# numerical_recipes

> **English TL;DR:** A chapter-organized practical companion to *Numerical Recipes* — one folder per chapter (linear algebra, interpolation, integration, special functions, random numbers, sort/select, minimization, eigensystems, FFT, ODE, PDE, computational geometry, etc.), focused on runnable numerical algorithms.

> 《Numerical Recipes》各章节的实践化整理，覆盖数值计算主要领域。

## 📖 项目简介

按《Numerical Recipes》章节体系组织的数值计算主题目录，每个章节一个独立文件夹，内容以可运行的数值算法与公式为核心。

## 🚀 使用

按需要进入对应章节目录，查看或运行其中的数值实现：

```bash
cd 12_Fast_Fourier_Transform   # 示例：FFT
ls .                           # 查看该章节的算法实现
```

## 📌 定位

数值计算的系统参考库，适合科研、工程与算法学习中需要可靠数值方法时查阅/复用。
